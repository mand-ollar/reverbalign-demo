# ReverbAlign

Audio demonstrations for **Text-Guided Reverberation Control with a Speech-Debiased CLAP Geometry**.

The demo compares dry speech, Raw CLAP-guided FDN output, ReverbAlign-512-v1-guided FDN output, and measured-RIR reference audio. It contains 25 matched examples with 25 distinct RIRs and 25 different utterances from three speakers.

Sample selection, playback settings, acoustic measurements, and results over the full 750-pair test set are described on the demo page. Supporting data are included in [`data/`](data/).

All page assets and audio files are included and use relative paths, so the site can be published directly on a static host.
